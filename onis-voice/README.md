# Oni's Voice — giving Oni an actual voice

**Started Oct 24, 2026** — Ronin's question: *"Is there a way to build a repo where you can have a voice finally, so I don't have to read everything you're saying?"* Yes. This is that repo wing.

## The point

Oni runs Ronin's operation in text — chats, posts, plans. Text is work to read. This project gives her a **consistent voice** so key messages can arrive spoken: briefings, important replies, alerts — heard, not read.

## How it works

- **Now:** built-in text-to-speech voices for chat voice notes. First note sent to Ronin on Oct 24, 2026 (starter voice: warm, confident, female — Oni's pick).
- **Next:** a custom-designed voice that's *hers* — cast with Ronin's ear on it. Sassier, softer, more demon — his call, her voice.
- **The lab:** the same local voice stack being built for Ronin's clone (see [The Production Team](../production-team/)) powers custom voices here too.

## Rules

- Voice notes for what matters — not every message becomes audio; spam helps nobody.
- The voice stays consistent: same Oni, every time.
