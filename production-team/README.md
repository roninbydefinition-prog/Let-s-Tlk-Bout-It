# The Production Team — LTBI Podcast Production Management

Not a generic content tool — a production crew for one show: **LTBI (Let's Talk Bout It)**, hosted by S.K. Ronin.

The idea: run the podcast like a studio with a staff. Each member of the team owns one stage of production, from raw topic to posted promo.

## The crew

- 🎬 **Showrunner** — owns the pipeline and the calendar: what's recording, what's owed, what ships when.
- 📝 **Producer** — turns raw topics into talking points and episode outlines. Never scripts — topics are real, scripts are fake.
- 🎚️ **Audio Engineer** — recordings (Craig, live in the LTBI Studio), cleanup, the episode vault — and the voice lab: a private clone of the host's voice for promo reads, reminders and ad spots.
- 📣 **Promo Manager** — graphics, captions and the posting schedule across Instagram, Threads, Facebook and TikTok.
- 📊 **Analyst** — watches performance, scores what's working, feeds it back to the Producer.

## The pipeline

Topic → talking points → record in the Studio → vault → promos → scheduled posts → analytics → next topic.
